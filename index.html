FAQ

常見問題

HoYo Daily 是 HoYoverse 官方工具嗎？

不是。HoYo Daily 是第三方社群工具，與 HoYoverse、HoYoLAB 沒有官方隸屬關係。原神、崩壞：星穹鐵道、絕區零及相關商標歸其各自權利人所有。

Windows 顯示 SmartScreen 警告怎麼辦？

新發布、下載量較少或沒有程式簽章的 EXE 可能出現 SmartScreen 警告。請先確認檔案來自 HoYo Daily 官方 GitHub Release，再決定是否執行。

GitHub 還沒建立，現在可以下載嗎？

HoYo Daily 的 GitHub Repository 與 V1.0.0 Release 已建立，網站下載按鈕會直接下載 V1.0.0 的 EXE；你也可以前往官方 Release 頁面查看版本資訊。

我需要每天自己操作嗎？

HoYo Daily 的設計目標是把登入後的簽到、兌換碼與執行紀錄流程自動化；實際自動化範圍以 V1.0.0 程式的實際功能為準。
